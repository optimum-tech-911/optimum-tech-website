UN PETIT GESTE. LE GRAND JEU.

Choisis ton appareil.

iPhone / iPad Android Ordinateur

Dans Safari, en trois gestes.

  1. 1

    Ouvre Partager

    Dans Safari, le partage est dans la barre d’outils ou dans le menu près de l’adresse.

  2. 2

    Choisis « Sur l’écran d’accueil »

    Si l’option manque, cherche-la dans « Modifier les actions ».

  3. 3

    Confirme avec « Ajouter »

    Garde « Ouvrir comme app web » activé si ce choix apparaît. Lance ensuite GMK Rush depuis son icône.

Sur Android, avec ton navigateur.

  1. 1

    Ouvre la page dans Chrome

    Quand l’installation est disponible, le bouton « Installer le jeu » apparaît en haut de cette page.

  2. 2

    Confirme l’installation

    Sans bouton, regarde dans le menu ⋮ du navigateur : « Installer l’application » ou « Ajouter à l’écran d’accueil ».

  3. 3

    Retrouve l’icône GMK Rush

    Ouvre le jeu depuis ton écran d’accueil. Tu peux aussi jouer ici sans l’installer.

La Riviera a aussi sa fenêtre.

  1. 1

    Dans Chrome ou Edge

    Utilise le bouton d’installation de cette page lorsqu’il apparaît, ou l’option Installer du navigateur.

  2. 2

    Sur Mac, dans Safari

    Choisis Fichier → Ajouter au Dock, puis confirme l’ajout.

  3. 3

    Et si l’option n’existe pas ?

    Le bouton Jouer lance toujours la version navigateur. L’installation dépend de ton navigateur et de ton appareil.
